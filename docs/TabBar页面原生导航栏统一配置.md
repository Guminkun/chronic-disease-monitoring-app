## 统一配置

### pages.json 配置

所有TabBar页面统一使用以下配置：

```json
{
  "navigationBarTitleText": "页面标题",
  "navigationBarBackgroundColor": "#ffffff",
  "navigationBarTextStyle": "black"
}
```

### 配置说明

**navigationBarBackgroundColor: "#ffffff"**
- 导航栏背景色统一为白色
- 与微信小程序设计规范一致
- 清爽简洁的视觉风格

**navigationBarTextStyle: "black"**
- 导航栏文字颜色为黑色
- 与白色背景形成良好对比
- 保证可读性

**navigationBarTitleText**
- 首页：显示应用名称"慢小二"，强化品牌
- 用药：简洁明了，突出功能
- 监测：简洁明了，突出功能
- 我的：通用做法，符合用户习惯

## 维护说明

### 如何修改导航栏样式

如需修改导航栏样式，只需修改 `pages.json`：

```json
{
  "navigationBarBackgroundColor": "#你的颜色",
  "navigationBarTextStyle": "black或white"
}
```

### 注意事项

1. **保持一致性**
   - 所有TabBar页面保持相同配置
   - 修改时同步修改所有页面

2. **颜色对比**
   - 背景色和文字颜色需有足够对比度
   - 建议使用白底黑字或深色底白字

3. **标题简洁**
   - 标题字数控制在2-4字
   - 首页可使用应用名称
