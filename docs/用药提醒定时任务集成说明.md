# 用药提醒定时任务集成说明

## 已完成集成

定时任务已集成到FastAPI后端服务中，**无需单独启动**，随FastAPI服务自动运行。

---

## 工作原理

### 1. 自动启动
- FastAPI服务启动时，定时任务自动启动
- FastAPI服务关闭时，定时任务自动停止

### 2. 检查频率
- 每60秒检查一次
- 检查当前时间是否匹配药品的服药时间

### 3. 发送逻辑
- 提前2分钟内发送提醒
- 检查用户订阅状态和剩余次数
- 发送成功后自动扣除订阅次数

## 配置说明

### 检查间隔

默认每60秒检查一次，可在 `scheduler.py` 中修改：

```python
class BackgroundScheduler:
    def __init__(self):
        self.check_interval = 60  # 修改这里（单位：秒）
```

### 提醒时间窗口

默认提前2分钟内发送提醒，可在 `scheduler.py` 中修改：

```python
reminder_window_start = now - timedelta(minutes=2)
reminder_window_end = now + timedelta(minutes=2)
```

## 注意事项

### 1. 生产环境部署

使用进程管理工具（如systemd、supervisor）管理FastAPI服务：

**示例 - systemd**:
```ini
[Unit]
Description=HealthMonitor API
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/path/to/backend
ExecStart=/usr/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
Restart=always

[Install]
WantedBy=multi-user.target
```

### 2. 多进程部署

如果使用多进程部署（如Gunicorn + Uvicorn），需要注意：

```bash
# 错误示例 - 会启动多个定时任务
gunicorn app.main:app -w 4 -k uvicorn.workers.UvicornWorker

# 正确示例 - 单独启动定时任务进程
# 方案1: 使用单worker
gunicorn app.main:app -w 1 -k uvicorn.workers.UvicornWorker

# 方案2: 将定时任务分离为独立服务（推荐生产环境）
# 独立运行定时任务
python -m app.tasks.medication_reminder
```

### 3. Docker部署

在Dockerfile中只需要启动FastAPI服务：

```dockerfile
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

定时任务会在以下情况记录日志：

- ✅ 发送失败时

### 常见问题

**Q: 定时任务没有运行？**
- 检查后端服务是否启动
- 查看日志中是否有"后台定时任务已启动"

**Q: 没有收到提醒？**
- 检查药品是否开启提醒
- 检查用户订阅状态和剩余次数
- 检查服药时间是否正确
- 使用测试脚本验证

**Q: 如何停止定时任务？**
- 停止FastAPI服务即可
- 定时任务会自动停止
