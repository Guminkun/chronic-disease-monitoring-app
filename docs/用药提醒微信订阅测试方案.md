# 用药提醒微信订阅功能测试方案

## 一、功能概述

### 1.1 需求背景
移动端用药模块需要添加提醒设置功能，接入微信小程序的消息订阅，使用微信原生的提醒功能。

### 1.2 功能目标
- 用户开启提醒时，引导订阅微信消息
- 到用药时间时，通过微信订阅消息提醒用户服药
- 删除铃声字段（微信小程序无法实现自定义铃声）

### 1.3 技术方案
使用微信小程序订阅消息功能，一次订阅可发送一次消息，用户可多次订阅累积次数。

### 2.1 前端改动

#### 2.1.1 删除铃声字段

### 2.2 后端改动

#### 2.2.1 已有接口（无需改动）
- `GET /medications/subscribe-message` - 获取订阅消息模板
- `POST /medications/confirm-subscription` - 确认订阅
- `GET /medications/subscription-status` - 查询订阅状态

#### 2.2.2 需要新增的接口
无需新增，现有接口已满足需求

#### 2.2.3 数据库模型
已有 `wechat_subscriptions` 表，包含：
- `user_id` - 用户ID
- `openid` - 微信用户标识
- `template_id` - 模板ID
- `is_subscribed` - 是否订阅
- `subscribe_count` - 订阅次数
- `used_count` - 已使用次数

## 四、微信订阅消息配置

### 4.1 申请订阅消息模板

**步骤**:
1. 登录微信公众平台
2. 进入"功能" -> "订阅消息"
3. 申请"用药提醒"类模板

**模板示例**:
```
用药提醒
{{thing1.DATA}}
服药时间：{{time2.DATA}}
服用剂量：{{thing3.DATA}}
注意事项：{{thing4.DATA}}
```

**字段说明**:
- `thing1`: 药品名称（最多20字）
- `time2`: 服药时间
- `thing3`: 服用剂量（最多20字）
- `thing4`: 注意事项（最多20字）

### 4.2 后端配置

**文件**: `backend/.env`

```env
# 微信小程序配置
WECHAT_APPID=wx1234567890abcdef
WECHAT_SECRET=your_app_secret_here
WECHAT_MEDICATION_TEMPLATE_ID=your_template_id_here
```

### 4.3 获取模板ID

配置完成后，后端接口 `/medications/subscribe-message` 会返回真实的模板ID。

## 九、风险评估

### 9.1 技术风险
| 风险项 | 影响 | 概率 | 应对措施 |
|-------|------|------|---------|
| 微信订阅消息审核不通过 | 高 | 中 | 提前申请，准备多种模板方案 |
| 用户拒绝订阅 | 中 | 高 | 提供应用内提醒备选方案 |
| 订阅次数用尽 | 中 | 高 | 提前提示用户续订 |

### 9.2 业务风险
| 风险项 | 影响 | 概率 | 应对措施 |
|-------|------|------|---------|
| 用户忘记续订 | 中 | 中 | 次数不足时主动提醒 |
| 提醒过于频繁 | 低 | 低 | 提供灵活的提醒时间设置 |
