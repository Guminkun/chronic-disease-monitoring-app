# 药品余量提醒逻辑优化

## 修改时间
2026-04-20

## 修改内容
消息中心的药品余量不足提醒，改为小于3天才提醒。

## 修改前后对比

### 修改前
- **提醒阈值：** 7天内（`remind_before_days = 7`）
- **提醒条件：** 剩余 0-7 天都会提醒
- **问题：** 提醒过早，用户可能觉得干扰

### 修改后
- **提醒阈值：** 小于3天（`remind_before_days = 2`）
- **提醒条件：** 剩余 0-2 天才会提醒
- **优势：** 更及时，减少不必要的打扰

### 提醒逻辑

**临时用药：**
- 计算剩余天数 = 结束日期 - 今天
- 如果 0 ≤ 剩余天数 ≤ 2，生成提醒

**长期用药：**
- 计算剩余天数 = 余量 / (单次剂量 × 每日次数)
- 如果 剩余天数 ≤ 2，生成提醒

## 用户体验提升

### 优化前的问题

1. **提醒过早**
   - 7天前就提醒，用户可能觉得太早
   - 提醒过多，用户可能忽略

2. **打扰用户**
   - 即使药品充足也会提醒
   - 影响用户体验

### 优化后的效果

1. **提醒及时**
   - 只在小于3天时提醒
   - 真正需要补充时才通知

2. **减少打扰**
   - 提醒数量大幅减少
   - 用户不会被过多消息打扰

3. **更符合用户预期**
   - 用户期望紧急时才提醒
   - 提升满意度
